Calendário

Ex: início 08:00, término 10:00, a cada 30 min → notifica às 08:00, 08:30, 09:00, 09:30 e 10:00.
Pode combinar vários assuntos por código (🔢) entre si, ou vários por palavra-chave (🔎) entre si, na mesma sessão. O que não dá é misturar código com palavra-chave numa mesma sessão — nesse caso, cadastre sessões separadas.
Cole o plano em JSON, uma sessão por item, com data, hora e assunto. Os nomes de matéria e assunto são procurados no catálogo do edital em uso ().
Ver o formato completo 
[
  {
    "data": "2026-10-19",         // AAAA-MM-DD ou DD/MM/AAAA
    "hora": "08:00",              // início (aceita "8h30"; ou faixa "08:00-10:00")
    "fim": "10:00",               // opcional (padrão: igual ao início = 1 alerta)
    "intervalo": 30,              // opcional, em minutos (padrão 30)
    "questoes": 10,               // opcional, por alerta (padrão 10)
    "materia": "Direito Constitucional",   // opcional se o assunto for único
    "assunto": "Controle de Constitucionalidade"
    // ou vários: "assuntos": ["Assunto A", "Assunto B"]
  }
]
Também vale um objeto { "sessoes": [ ... ] }, e o JSON pode vir dentro de um bloco de código (```). Os comentários // acima são só explicação e não devem ir no JSON.

Matérias e assuntos —

Cole a lista de matérias com os assuntos de cada uma. Tudo entra no edital em uso (); o que já existe é ignorado, então dá para importar mais de uma vez.
Ver o formato completo 
[
  {
    "materia": "Língua Portuguesa",
    "peso": 4,                          // opcional: importância na prova
    "assuntos": [
      "Crase",                          // só o nome = busca por palavra-chave
      { "nome": "Concordância verbal" },                         // idem
      { "nome": "Interpretação de texto", "codigo": "403701" },  // por código do Gran Cursos
      { "nome": "Pontuação", "codigo": "409551, 409455" }        // vários códigos no mesmo assunto
    ]
  },
  { "materia": "Informática", "assuntos": ["Redes de computadores"] }
]
Também vale o formato compacto { "Língua Portuguesa": ["Crase", "Pontuação"] } e um objeto { "materias": [ ... ] }. Para buscar por um termo diferente do nome, use "palavraChave". Os comentários // acima são só explicação e não devem ir no JSON.
Esses parâmetros ficam fixos na URL para todas as sessões. Copie os valores da sua URL de exemplo do Gran Cursos.
